# QuizPulse — Brand assets

## Mark

`public/brand/quizpulse-mark.svg` — hand-authored SVG, no font dependency.

- 100×100 viewBox, ink `#201e1d` square background
- White circle ring (stroke-width 8) — the Q body
- Terracotta `#ca2910` diagonal line (stroke-linecap square) — the Q tail
- Zero rounding everywhere

The `<BrandMark size={n} />` React component (`src/components/BrandMark.jsx`) inlines this SVG
and is used in: Sidebar, DemoNav, Login (all three variants), Onboarding, OnboardingProfile, Home.

## Typeface

Archivo Variable, self-hosted at `public/fonts/archivo-variable.woff2`. Latin subset, `font-display: swap`.
Four `@font-face` blocks in `src/index.css` back weights 400/600/700/800.
