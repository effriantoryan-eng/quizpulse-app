Quiz completion (student)

The completion screen appears after a student submits. Below the main message, an encouragement line is shown (one chosen at random on each submission). The two streak treatments appear side-by-side for comparison — only one would ship.

Option B — Softer

Design note: Option A uses a flame icon and a numerical count ("4 in a row") which is clear but can create pressure. Option B drops the number and icon, framing it as presence ("shown up") rather than achievement. Neither shows a score or marks. Recommend Option B for low-stakes framing.
